# 工作流紀錄

## 1. 範圍
實作題目指定的 C++ Dijkstra，並以繁體中文靜態網頁逐步呈現同一張無向加權圖與演算法狀態。網頁可部署至 GitHub Pages。

## 2. 規格
- 節點 0–5 對應圖中的 A–F；起點 0，終點 5。八條邊及權重完全依題目。
- 使用鄰接串列、(距離, 節點) 最小堆、過期條目跳過與 parent。
- 嚴格改善才更新距離，保留先找到的同長路徑；輸出距離 9、0→1→3→5。
- 網頁呈現圖、佇列、距離與 parent、操作步驟，提供上一步、下一步、自動播放、重來。
- 演算法僅適用非負邊權；說明定案原理及相同距離的情形。

## 3. 計畫
先寫可重現的 C++ 與網頁邏輯測試並確認失敗；實作演算法、逐步模擬與介面；執行測試、瀏覽器檢查，最後上傳 GitHub 並確認 Pages。

## 4. 計畫審查
- 圖片的 A–F 與題目 0–5 映射一致，八條邊與權重一致。
- 題目要求的路徑並非唯一：0→1→2→4→3→5 也是 9；比較採 `<`，不因相等而改寫 parent。
- 定案證明必須允許其他候選點距離「相等」，不能說一定嚴格更大；非負權重是必要前提。
- 過期條目不可視為定案；畫面需顯示跳過。
- 網頁與 C++ 各自運算，因此測試需覆蓋兩者的結果和過期條目。

## 5. TDD 與驗證
執行 `bash tests/run.sh`。測試先建立，再完成程式；包括指定答案、無法抵達、起點自身、同長路徑與過期條目。網頁另外需以瀏覽器驗證步驟與版面。
